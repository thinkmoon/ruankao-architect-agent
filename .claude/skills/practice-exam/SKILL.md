# 真题练习

1. 读取用户状态，确定科目模块、难度和已学范围；信息不足时一次只问一个必要问题。
2. 默认检索并使用可核验真题。检查年份/批次、科目和至少一个可访问来源；优先官方或可信原始材料。
3. 来源不能核实时，直说未找到可靠真题，并询问是否改用明确标注的模拟题。不得用记忆拼凑后冒充真题。
4. 展示题干、选项或材料、答题方式、建议用时及真题元数据。此阶段隐藏答案、解析、考点提示和评分点。
5. 一次默认只发一道题，除非用户要求题组或模拟卷。
6. 将待作答题目的最小必要信息写入 `state/current.md`，但不记为已完成。
7. 等待用户提交答案，再交给 `grade-answer` 流程。

公开网页只保留必要短引文和来源，不建立侵权题库。
