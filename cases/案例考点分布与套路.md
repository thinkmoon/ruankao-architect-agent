## 各类题型答题套路

### 试题一：架构设计与评估

**质量属性场景题**
- 格式：刺激 → 制品 → 环境 → 响应 → 响应度量
- 六大质量属性：性能、可用性、可修改性、安全性、可测试性、易用性
- 关键词对应：
  - 性能 → 响应时间、吞吐量、并发数
  - 可用性 → 故障恢复时间、MTBF、冗余
  - 可修改性 → 变更代价、影响范围、耦合度

**ATAM评估题**
- 步骤：呈现ATAM → 呈现业务驱动 → 呈现架构 → 识别架构方法 → 生成质量属性效用树 → 分析架构方法 → 头脑风暴场景 → 分析场景 → 结果呈现
- 效用树格式：质量属性 → 属性精化 → 场景（H/M/L优先级，H/M/L实现难度）

**架构风格选择题**
- 常见风格：管道-过滤器、面向对象、事件驱动、SOA、微服务、分层
- 答题要求：说明选用理由 + 该风格与需求的对应关系

### 试题二：UML建模

**用例图**
- 参与者（Actor）、用例（Use Case）
- 关系：包含（<<include>>）、扩展（<<extend>>）、泛化（继承箭头）

**类图填空**
- 关系：关联、依赖、聚合（空菱形）、组合（实菱形）、继承（空三角）、实现（虚线空三角）
- 多重性：1, 0..1, 1..*, 0..*, n..m

**顺序图**
- 生命线、激活条、同步消息（实线实心箭头）、返回消息（虚线）
- 循环框（loop）、可选框（opt）、替代框（alt）

**状态图/活动图**
- 初态（实心圆）、终态（同心圆）、转换条件、分支合并

### 试题三/四：嵌入式系统

**常考知识点**
- 实时性：硬实时（错过截止时间导致灾难）vs 软实时
- 调度算法：最早截止时间优先（EDF）、速率单调（RMA）
- 可靠性：冗余设计（热备/冷备/温备）、故障检测、看门狗
- 总线协议：CAN、LIN、SOME/IP、DDS

**答题格式**
1. 指出系统类型（硬实时/软实时）及理由
2. 说明选用的设计策略
3. 结合题目场景说明实现方式

### Redis/缓存题

**必背知识点**
| 问题类型 | 原因 | 解决方案 |
|---------|------|---------|
| 缓存穿透 | 查询不存在的key | 布隆过滤器、缓存空值 |
| 缓存击穿 | 热点key过期瞬间大量请求 | 互斥锁、逻辑过期、永不过期 |
| 缓存雪崩 | 大量key同时过期 | 随机TTL、主从集群、限流降级 |
| 数据不一致 | 缓存与DB不同步 | 先删缓存再更新DB、延时双删 |

**持久化**
- RDB：快照，适合备份，恢复快，可能丢数据
- AOF：日志追加，数据更安全，文件大，恢复慢
- 混合持久化：RDB+AOF（Redis 4.0+）

**主从复制流程**：全量同步（RDB）→ 增量同步（repl_backlog）→ 命令传播
